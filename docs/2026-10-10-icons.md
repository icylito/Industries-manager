# Icons: Font Awesome as a plain font (2026-10-10, night)

## Why

Pressing **Bring back** on a History version the size of the real table (5,001 rows) never showed the preview. The tab froze, grew to about 4 GB and crashed.

It wasn't the API. The preview answers in about 0.1 s (1.3 MB of JSON).

The cause was the hosted Font Awesome kit (`kit.fontawesome.com/9722f49037.js`, set to `autoReplaceSvg: 'nest'`). Its script watches every change to the page and swaps each `<i class="fa-...">` for an SVG. The preview has a warning triangle on every repeated row, and the kit's work grew far faster than the row count. A CPU profile showed its functions (`nest`, `generateSvgReplacementMutation`) doing most of the work. Blocking that one script fixed it.

| Bring back preview | Before | After |
|---|---|---|
| 282 rows | ~2 s | 0.1 s |
| 5,001 rows | froze, ~4 GB, crashed | 0.8 s, 42 MB |

Also measured after the change:
- Browse with 5,001 companies shows in 0.66 s.
- A real Bring back of all 5,001 rows takes 1.5 s.
- Browse with 10,002 companies shows in 0.75 s.
- No page errors.

## What changed

- `angular/package.json`, `angular/package-lock.json`: `@fortawesome/fontawesome-free` pinned at `6.7.2`.
- `angular/scripts/icons.mjs` (new) writes `angular/src/icons.css` (new). It keeps the package's base rules and only the 86 icons the app uses. It is 12 KB, and the page grew from 467 to 477 kB.
  - The two fonts (`fa-solid-900.woff2`, `fa-regular-400.woff2`) are copied by the build as separate files. They load only when an icon shows.
- `angular/angular.json`: `src/icons.css` added before `src/styles.css`, in the build's `styles`.
- `angular/src/index.html`: the kit `<script>` and `window.FontAwesomeConfig` are removed. The page no longer calls `kit.fontawesome.com`, so icons work without internet too.

## When you use a new icon

Run `node scripts/icons.mjs` in `angular/`, then commit `src/icons.css`.

`node scripts/icons.mjs --check` fails when an icon in the code is missing from `src/icons.css`. Icon names must appear whole in the code (`fa-camera`), never built from pieces, or the script can't see them.

## Assumptions

- All icons the app uses are in the free set. The script found every name used in `src/app` in the free package, and four pages checked in a browser showed no empty icons.
- The kit gave the same Font Awesome 6 classes. If the kit had Pro icons, they weren't used anywhere.

## To undo

1. In `angular/src/index.html`, put back before `</head>`:
   ```html
   <script>window.FontAwesomeConfig = { autoReplaceSvg: 'nest' };</script>
   <script src="https://kit.fontawesome.com/9722f49037.js" crossorigin="anonymous"></script>
   ```
2. Remove `"src/icons.css"` from `styles` in `angular/angular.json`.
3. Delete `angular/src/icons.css` and `angular/scripts/icons.mjs`. Run `npm uninstall @fortawesome/fontawesome-free` in `angular/`.

Or revert the commit "icons are font awesome free as a plain font...". The Bring back freeze comes back with the kit.

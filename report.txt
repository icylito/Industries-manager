SMALL EDGE CASES (add a Vitest spec for each one, and fix the code if it fails)
E1  The sign in page's `back` link. In angular/src/app/Components/login/login.ts only values that start with "/" and not "//" are followed. A value like "/\evil.com" is read by browsers as "//evil.com". Refuse any value containing a backslash, a colon or a line break, and fall back to "/". Test: back=/history goes there, back=//evil.com, back=/\evil.com, back=https://evil.com, back=%0d%0a all go to "/".
E2  Auth service with blocked storage. In angular/src/app/services/auth.ts, when localStorage throws, the token must still work for the visit from memory and sign out must clear it. Test with a localStorage that throws on every call.
E3  Interceptor. In angular/src/app/services/auth.interceptor.ts: a 401 from /auth/login must not redirect; a 401 from another call must clear the person and go to /login with back set to the page they were on; a 403 whose body title is "New password needed" must go to /account; a 403 with another title must not redirect. Calls to other sites must never get the token (already tested) and must never trigger a redirect on 401.
E4  downloadFile in angular/src/app/services/industry-api.ts reads the file name from Content-Disposition. Test: `attachment; filename=settings-2026-10-06.json; filename*=UTF-8''settings-2026-10-06.json`, a quoted name with spaces, a percent-encoded name (%E6%97%A5%E6%9C%AC.csv), no header at all (uses the fallback name), and an error response (the error reaches the caller and nothing is downloaded).
E5  Retention boxes in history.ts: toNumber('') is null, toNumber('abc') and toNumber('-5') and toNumber('2.7') must never send NaN or a negative number. Make them show "Use a whole number of 1 or more" and not send. 2.7 becomes 2.
E6  Settings import file in history.ts: refuse a file bigger than 1 MB before reading it ("That file is too big to be a settings file"), refuse a file that isn't JSON (already handled, add the test), and a JSON file that is an array or has no app field gets the API's message.
E7  Users page (angular/src/app/Components/users/users.ts): the add person box trims spaces and lower cases the name before sending; an empty name shows "Type a username" and sends nothing; the temporary password panel is cleared when the page is left (destroy) and can't be copied twice into a failed clipboard (if navigator.clipboard is missing, show "Select the password and copy it yourself").
E8  Account page: new password under 10 characters, two new passwords that differ, and a new password equal to the current one are all stopped on the page with plain messages before any call is made. Test that no request is sent in those three cases.
E9  Guest view: with nobody signed in the main table has no Actions column, no Add form, and no calls to /requests or /requests/count (assert with the HTTP testing controller). With an account it has all three.
